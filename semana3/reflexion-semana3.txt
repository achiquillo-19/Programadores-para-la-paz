reflexion semana3
Mantener un registro de cambios en los proyectos de software es esencial para garantizar el control y la organización del trabajo. Git permite guardar cada modificación realizada, facilitando volver a versiones anteriores si ocurre un error. Además, ayuda a que varios desarrolladores trabajen en el mismo proyecto sin conflictos, ya que cada cambio queda documentado. Esta trazabilidad mejora la colaboración, la transparencia y la calidad del código. Usar Git también fomenta buenas prácticas profesionales, como escribir mensajes claros en los commits y mantener un historial limpio. En resumen, Git es una herramienta clave para el desarrollo moderno y el aprendizaje de gestión de versiones.
